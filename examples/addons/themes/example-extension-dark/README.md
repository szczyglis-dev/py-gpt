# Example theme Add-on

This is a static `theme` Add-on. It contains no Python entry point. Files under `theme/` are copied into the profile theme directory at installation and are loaded by the normal PyGPT theme system.

Install the directory, restart if needed, and select the theme from the appearance/theme menu. Edit `theme/app.css` to experiment with QSS/CSS overrides. A real theme can also provide the other supported theme assets documented in Configuration.
